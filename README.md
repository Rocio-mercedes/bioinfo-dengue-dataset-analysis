Análisis categórico de datos de Dengue

Primer proyecto de bioinformática y análisis de datos biológicos
Autora: Rocío Sandez
Descripción del proyecto

Este repositorio contiene un análisis exploratorio de un dataset categórico relacionado con Dengue.
El objetivo principal fue practicar:

organización de datos biológicos

análisis descriptivo

gráﬁcos de distribución de categorías

interpretación de resultados

Este es mi primer proyecto dentro de mi portafolio en GitHub orientado a virología, genética y bioinformática.
