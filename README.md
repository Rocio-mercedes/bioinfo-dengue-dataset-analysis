Objetivo del proyecto

Este repositorio contiene un análisis exploratorio de un dataset categórico relacionado con Dengue.
El objetivo fue practicar:

organización de datos biológicos

análisis descriptivo

gráficos de distribución de categorías

interpretación de resultados

Este es mi primer proyecto para construir mi portafolio en GitHub orientado a virología, genética y bioinformática.
